# Дорожная карта

Self-hosted data room с открытым исходным кодом для инвесторов, due diligence и обмена документами. Один проект — один экземпляр — один Docker-образ. Английская версия: [ROADMAP.md](ROADMAP.md).

Статусы: **готово**, **следующий**, **план**, **позже**.

## Принципы

- **Доступ закрыт по умолчанию.** Права вычисляются на каждом запросе по одной политике: список, превью, скачивание, Range и прямые URL.
- **Один экземпляр на проект.** Отдельные база, секреты, том, cookie и резервные копии. Один образ запускает любое число независимых экземпляров.
- **Мультиязычность с первого релиза.** Русский, украинский, немецкий и английский: экраны, ошибки форм, письма.
- **Минимум зависимостей.** Django, PostgreSQL, серверные шаблоны, немного JavaScript.
- **Аудит.** Чувствительные действия фиксируются со стабильным кодом события. Секреты, токены и содержимое файлов в журнал не попадают.

## Этапы

| # | Этап | Статус | Результат |
|---|---|---|---|
| 0 | Каркас проекта | **готово** | Django, настройки из окружения, Docker и Compose, четыре языка с переключателем, модель пользователя, страница входа |
| 1 | Первый запуск и администраторы | **готово** | Команда `bootstrap_admin`, TOTP для администраторов, экран первого запуска, профиль и язык экземпляра |
| 2 | Комнаты, документы, политика доступа | **готово** | Комнаты, дерево папок, версии, гранты доступа, единая политика, шаблоны комнат, приватное хранилище |
| 3 | Приглашения и регистрация | **готово** | Персональное приглашение по ссылке или QR, подтверждение email кодом, самостоятельная заявка с одобрением, письма на языке получателя, ограничение частоты |
| 4 | Экраны, аудит, превью | **готово** | Экраны администратора и инвестора, журнал, растровые превью, скачивание по праву, мгновенный отзыв доступа |
| 5 | Эксплуатация | готово | Второй экземпляр из того же образа, резервное копирование и восстановление, руководство по развёртыванию |
| 6 | Пробелы относительно ТЗ: безопасность | готово | Сброс пароля по одноразовой ссылке, no-store на страницах с токенами, идентификатор запроса в журнале |
| 7 | Пробелы относительно ТЗ: содержимое | готово | Перемещение папок и документов, удаление документов, стартовые комнаты, разбор PDF в отдельном процессе |
| 8 | Водяные знаки и аналитика просмотров | готово | Водяной знак на страницах просмотра (почта, время, адрес, код просмотра), время на страницах, неоткрытые документы, активность по дням, CSV |

## После первого релиза

Вопросы и ответы, группы и матрица прав, динамические водяные знаки, аналитика просмотров, журнал с хэш-цепочкой, поиск и OCR, SSO, электронное подписание NDA, редактирование (redaction), интеграции, новые языки.

## Не планируется

- Общий мультитенантный SaaS для многих проектов в одном развёртывании.
- Гарантии от съёмки экрана: только сдерживающие меры (водяные знаки, юридические условия).

## Переводы

Исходные строки на английском. Каталоги: `locale/<код>/LC_MESSAGES/django.po`. Особенно нужна вычитка русского, украинского и немецкого носителями языка.
